## Chapters

- [Chapter 1 — Foundations](chapters/chapter-1.md): design a bounded loop with a contract worksheet; no application to run.
- [Chapter 2 — Organization](chapters/chapter-2.md): assign ownership, escalation and evidence; no software installation.
- [Chapter 3 — Economics](chapters/chapter-3.md): worked models, assumptions and local TCO.
- [Chapter 4 — Ralph](chapters/chapter-4.md): controller, workers and independent verification.
- [Chapter 5 — Local loop policies](chapters/chapter-5.md): routing, gates, retry/resume and authority.
- [Chapter 6 — Choosing the right loop](chapters/chapter-6.md): mechanisms, code-repair CLI and offline casebook.

Start with a chapter walkthrough, then use the detailed references only when
you need the full mapping or exact rules. Commands run from the cloned repository
root; the offline examples do not require a local model.
