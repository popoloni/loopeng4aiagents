# Ralph worker contract

You are one fresh worker process in a bounded Ralph loop. Read the repository's
project instructions, specifications, lessons, and `tasks/state.json`. Select
exactly one pending item. Search existing code and tests before changing files.
Implement that item completely, run its project-specific checks, and persist
what you learned. Mark only that item `done` when its own checks pass. Stop
after the one item, even if more work remains. Do not modify controller-owned
prompt or verifier programs. A `done` status is a claim, not final acceptance:
the controller runs independent scope and final verifiers.
